APIs

Ejemplo de consumo de una API utilizando información de objetos cercanos a la Tierra.

Una API (Application Programming Interface) permite que diferentes aplicaciones puedan comunicarse e intercambiar información.

En este ejemplo utilizamos una API de NASA para consultar información sobre objetos cercanos a la Tierra.

Objetos cercanos a la Tierra

Los siguientes datos son obtenidos directamente desde la API de NASA.

Presiona el botón para consultar los datos.

Dato Descripción
Nombre Nombre del objeto espacial.
Diámetro Tamaño estimado del objeto.
Velocidad Velocidad del objeto.
Distancia Distancia aproximada respecto a la Tierra.
Peligroso Indica si NASA lo clasifica como potencialmente peligroso.
