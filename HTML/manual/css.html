CSS

CSS significa Cascading Style Sheets, que en español significa Hojas de Estilo en Cascada.

CSS es un lenguaje utilizado para definir el diseño y la apariencia de las páginas web. Trabaja principalmente junto con HTML para transformar una estructura sencilla en una página visualmente organizada y atractiva.

¿Qué es CSS?

CSS es un lenguaje de estilos que permite controlar la apariencia de los elementos de una página web.

¿Para qué sirve?

Sirve para modificar la presentación de una página, incluyendo colores, tamaños, fuentes, fondos, espacios, bordes y distribución de los elementos.

Características principales

  • Cambia colores y fondos.
  • Modifica tipos y tamaños de letra.
  • Permite crear bordes.
  • Permite organizar elementos.
  • Permite crear animaciones.
  • Permite adaptar las páginas a celulares.
Ejemplo: CSS permite cambiar la apariencia de un título HTML para hacerlo más grande, cambiar su color y agregarle un fondo.

Selectores CSS

Los selectores indican qué elementos HTML recibirán los estilos definidos en CSS.

Tipos de selectores

  • Etiqueta: selecciona elementos como p, h1 o div.
  • Clase: utiliza el símbolo punto.
  • ID: utiliza el símbolo #.
  • Universal: utiliza el símbolo *.
Ejemplo:

h1 { color: blue; }

Este código cambia el color de todos los elementos h1 a azul.

Colores y fondos

CSS permite cambiar los colores de los textos, fondos y diferentes elementos de una página.

¿Para qué sirve?

Sirve para mejorar la apariencia visual de una página y diferenciar sus diferentes secciones.

Propiedades principales

  • color: cambia el color del texto.
  • background-color: cambia el color del fondo.
  • background-image: permite colocar imágenes de fondo.
Ejemplo:

body { background-color: beige; color: black; }

Bordes en CSS

Los bordes permiten agregar líneas alrededor de los elementos HTML.

¿Para qué sirven?

Sirven para destacar elementos, separar secciones y mejorar la presentación visual.

Propiedades

  • border
  • border-color
  • border-width
  • border-style
  • border-radius
Ejemplo:

.caja { border: 3px solid green; border-radius: 10px; }

Modelo de caja o Box Model

En CSS todos los elementos HTML pueden entenderse como cajas.

Partes principales

  • Content: contenido.
  • Padding: espacio interno.
  • Border: borde.
  • Margin: espacio externo.
El Box Model es importante porque permite controlar el tamaño y los espacios que existen alrededor de los elementos.

¿Qué es Flexbox?

Flexbox es un sistema de diseño de CSS que permite organizar elementos dentro de un contenedor.

¿Para qué sirve?

Sirve para colocar elementos en filas o columnas, alinearlos y distribuir el espacio disponible.

Propiedades importantes

  • display: flex;
  • justify-content
  • align-items
  • flex-direction
  • gap
Ejemplo:

.contenedor { display: flex; justify-content: center; gap: 20px; }

Diseño Responsive

El diseño responsive permite que una página web se adapte a diferentes tamaños de pantalla.

¿Para qué sirve?

Permite que una página funcione correctamente en computadores, tablets y teléfonos celulares.

Media Queries

Las Media Queries permiten aplicar diferentes estilos dependiendo del tamaño de la pantalla.

Ejemplo:

@media (max-width: 768px) { body { font-size: 14px; } }

Animaciones y transiciones

CSS permite crear efectos visuales y movimientos en los elementos de una página.

Transiciones

Las transiciones permiten realizar cambios suaves entre diferentes estados de un elemento.

Ejemplo:

button { transition: 0.3s; } button:hover { background-color: green; }

Animaciones

Las animaciones permiten crear movimientos y cambios utilizando reglas como @keyframes.
