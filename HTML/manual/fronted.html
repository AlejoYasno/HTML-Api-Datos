Frontend

El Frontend es la parte de un sitio web con la que el usuario interactúa directamente. Incluye botones, menús, imágenes, formularios, textos, colores y animaciones.

Para desarrollar el Frontend se utilizan principalmente HTML, CSS y JavaScript. Estas tecnologías permiten crear páginas web funcionales, atractivas e interactivas.

¿Qué es Frontend?

El Frontend es la parte visible de una página web o aplicación. Es todo aquello que el usuario puede observar y utilizar directamente.

¿Para qué sirve?

Sirve para crear la interfaz gráfica de una página web y permitir que el usuario pueda interactuar con ella.

Características principales

  • Permite la interacción con el usuario.
  • Diseña la apariencia de las páginas.
  • Permite crear botones y menús.
  • Permite utilizar imágenes y videos.
  • Permite crear animaciones.
  • Puede adaptarse a celulares y tablets.
Ejemplo: Cuando entramos a una página web y vemos botones, imágenes, textos, menús y formularios, estamos viendo elementos del Frontend.

¿Qué es HTML?

HTML significa HyperText Markup Language. Es el lenguaje utilizado para crear la estructura de una página web.

¿Para qué sirve?

HTML sirve para organizar el contenido de una página web. Permite crear títulos, párrafos, imágenes, enlaces, tablas, formularios y videos.

Características

  • Define la estructura de una página.
  • Utiliza etiquetas HTML.
  • Permite insertar imágenes.
  • Permite crear formularios.
  • Trabaja junto con CSS y JavaScript.
Ejemplo:

<h1>Mi página web</h1>

Esta etiqueta crea un título principal.

¿Qué es CSS?

CSS significa Cascading Style Sheets, o Hojas de Estilo en Cascada.

CSS permite cambiar la apariencia de los elementos HTML y crear diseños más atractivos.

¿Para qué sirve?

Sirve para cambiar colores, tamaños, fuentes, márgenes, bordes, fondos, posiciones, animaciones y otros aspectos visuales.

Características

  • Cambia los colores.
  • Modifica las fuentes.
  • Crea bordes.
  • Permite utilizar Flexbox.
  • Permite utilizar Grid.
  • Permite crear animaciones.
  • Permite crear diseños responsive.
Ejemplo:

h1 { color: blue; background-color: beige; }

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado para agregar interactividad a las páginas web.

¿Para qué sirve?

Permite responder a las acciones realizadas por los usuarios. Por ejemplo, puede mostrar mensajes, validar formularios, realizar cálculos y modificar contenido.

Características

  • Crea páginas interactivas.
  • Responde a eventos.
  • Valida formularios.
  • Modifica elementos HTML.
  • Permite crear aplicaciones web.
Ejemplo:

alert("Bienvenido a mi página");

Este código muestra un mensaje en pantalla.

¿Qué es Responsive?

El diseño Responsive permite que una página web se adapte a diferentes tamaños de pantalla.

¿Para qué sirve?

Sirve para que una página pueda visualizarse correctamente en computadores, tablets y celulares.

Características

  • Se adapta a diferentes pantallas.
  • Mejora la experiencia del usuario.
  • Funciona en celulares.
  • Utiliza CSS y Media Queries.
  • Organiza los elementos según el espacio.
Ejemplo: Una página puede mostrar tres columnas en un computador y una sola columna cuando se abre desde un celular.
